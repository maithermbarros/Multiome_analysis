# Multiome_analysis
Code repository for [“Single-nucleus multiome sequencing identifies candidate regulators of mouse gastric epithelial homeostasis”](https://doi.org/10.1101/2021.12.23.471999). 

Includes pipelines for snRNA-seq/snATAC-seq processing (**Seurat/Signac**), enhancer-driven gene regulatory network inference (**SCENIC+**), trajectory analysis (**MultiVelo**), epigenetic **plasticity scores**, and **EpiCHAOS** analysis of 31,598 nuclei from healthy mouse stomach tissue.
